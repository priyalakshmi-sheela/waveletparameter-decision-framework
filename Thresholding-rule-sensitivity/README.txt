# Thresholding-Rule Sensitivity: Wavelet Impulse Suppression in an OFDM Receiver under AWGN and Impulsive Noise

Supplementary code for:

> P. Sheela and I. Dey, "Advances in Wavelet Denoising for Communication Signals: From Parameter Selection Toward Data-Driven Optimization," *IEEE Open Journal of the Communications Society*, to appear.

The code reproduces the thresholding-rule comparison of Section IV-D:

- **Fig. 12:** BER of an OFDM/QPSK receiver with wavelet impulse suppression (db4, J = 3) using the hard, soft and garrote thresholding rules, under (a) AWGN and (b) Middleton Class-A impulsive noise.
- **Supplementary Fig. S1:** the same comparison under AWGN for every mother wavelet ψ ∈ {haar, db4, sym4, coif4, bior4.4} and decomposition level J ∈ {2, 3, 4, 5}.
- **Supplementary Fig. S2:** the same grid under Middleton Class-A impulsive noise.

---

## 1. Description

The code does the following:

1. Generates 120 OFDM/QPSK frames at each Eb/N0 value from 0 to 16 dB, in steps of 2 dB.
2. Passes every frame through two channels: complex AWGN, and complex Middleton Class-A impulsive noise. Both channels receive the same transmitted frames.
3. Applies wavelet impulse suppression to the received frames with every combination of mother wavelet, decomposition level and thresholding rule (60 configurations), then demodulates them and counts the bit errors. The receiver without denoising is evaluated as the reference.
4. Draws Fig. 12 from the db4, J = 3 configuration, and Supplementary Figs. S1 and S2 from all 20 wavelet–level combinations.

Fig. 12 and Figs. S1 and S2 come from one simulation, so the db4, J = 3 panel of Figs. S1 and S2 is identical to Fig. 12. Everything is generated from one seeded random stream, so every run gives exactly the same bit-error counts and the same figures.

The code is available in two forms:

- **Script.** `thresholding_rule_sensitivity.py` runs everything end to end in under 1 minute.
- **Notebook.** `stage_by_stage_thresholding.ipynb` runs the same stages one at a time, so you can inspect the intermediate results.

### 5.1 Signal and noise model

| Item | Setting |
|---|---|
| OFDM | 64-point FFT, 16-sample cyclic prefix, 48 active subcarriers (IEEE 802.11a data-subcarrier layout), QPSK |
| Frame | 14 OFDM symbols = 1120 complex samples = 1344 bits; waveform normalised to unit average power |
| Eb/N0 | 0, 2, 4, …, 16 dB (9 values); total noise power per sample σ² = Eb/(Eb/N0), with Eb = frame energy / 1344 |
| AWGN | Circular complex Gaussian noise of power σ² |
| Impulsive noise | Complex Middleton Class A of total power σ², impulsive index A = 0.005, Gaussian-to-impulsive power ratio T = 0.05, Poisson mixture truncated to 30 terms |
| Frames | 120 per Eb/N0 value, i.e. 161,280 bits per Eb/N0 value |
| Random stream | One NumPy generator with seed 21. For each frame it draws, in order, the bits, the AWGN and the impulsive noise. |

### 5.2 Impulse-suppression receiver

The in-phase and quadrature components are processed separately by the same real-valued DWT, with periodization boundary handling. For each component:

1. **Decompose** the component with the DWT to level J.
2. **Threshold each detail level.** In each detail level, the threshold is T = 4σ, where σ = median(|c|)/0.6745 is that level's noise estimate. The coefficients with |c| ≥ T form the impulse estimate, shaped by the thresholding rule:
   - hard: c;
   - soft: sgn(c)·(|c| − T);
   - garrote: c·(1 − T²/c²).

   All other coefficients, and the approximation, are set to zero.
3. **Reconstruct** the impulse estimate and subtract it from the received component.

The receiver then removes the cyclic prefix, computes the FFT, takes the 48 active subcarriers and makes hard QPSK decisions.

### 5.3 Configurations

| Parameter | Values |
|---|---|
| Mother wavelet ψ | haar, db4, sym4, coif4, bior4.4 |
| Decomposition level J | 2, 3, 4, 5 |
| Thresholding rule | hard, soft, garrote |
| Threshold | 4 × MAD noise estimate of each detail level (fixed) |

That gives 5 × 4 × 3 = 60 configurations, each evaluated under both noise models. All levels are admissible for 1120-sample frames. Fig. 12 uses ψ = db4 and J = 3.

### 5.4 Metric

**BER** is the number of bit errors of the hard QPSK decisions divided by the number of transmitted bits (161,280 per Eb/N0 value and channel). The receiver without denoising gives one BER curve per channel; it is drawn in every panel as the reference.

## 6. Setup instructions

Install Python 3.9 or newer from <https://www.python.org>. On Windows, tick **"Add Python to PATH"** during installation.

### Terminal

Open a terminal in this folder and run:

```
python -m venv .venv
.venv\Scripts\activate             (Windows)
source .venv/bin/activate          (Linux / macOS)
pip install -r requirements.txt
pip install ipykernel              (only needed for the notebook)
```

On Windows, if `python` is not recognised, use `py` instead. On Linux and macOS, `python3` may be needed.

## 7. Run instructions

With the environment activated:

```
python thresholding_rule_sensitivity.py
```

For the notebook, run `pip install notebook`, then `jupyter notebook stage_by_stage_thresholding.ipynb`.
