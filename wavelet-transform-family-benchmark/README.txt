# Transform-Family Benchmark: DWT, SWT and WPT Impulse Suppression in an OFDM Receiver

Supplementary code for:

> P. Sheela and I. Dey, "Advances in Wavelet Denoising for Communication Signals: From Parameter Selection Toward Data-Driven Optimization," *IEEE Open Journal of the Communications Society*, to appear.

The code reproduces the communication-oriented comparison of the best DWT-, SWT- and WPT-based denoising configurations on the OFDM–Middleton Class-A impulsive-noise benchmark:


## 1. Description

For each transform family (DWT, SWT, WPT), the code does the following:

1. Generates OFDM frames at 60 matched operating points. These combine Eb/N0, the Middleton Class-A parameters A and T, and the random seed.
2. Applies every configuration of a declared search space to all frames: 54 configurations per family, 162 in total. The search space covers the mother wavelet, the decomposition level, the threshold function and the threshold rule.
3. Selects, for each family, the configuration with the largest mean denoising gain.
4. Measures the per-frame processing time of the three selected configurations.
5. Reports the following:
   - mean ± 95 % confidence interval of ΔSNR, NMSE, BER and EVM (Table 6);
   - processing time, FLOP proxy and minimum frame budget (Table 7);
   - Friedman tests (Table 8);
   - pairwise Wilcoxon signed-rank tests, Holm-corrected.


The validation is available in two forms:

- **Script.** `transform_family_benchmark.py` runs everything end to end in about 1 minute.
- **Notebook.** `stage_by_stage_benchmark.ipynb` runs the same stages one at a time, so you can inspect the intermediate results.

### 5.1 Signal and noise model

| Item | Setting |
|---|---|
| OFDM | 64-point FFT, 16-sample cyclic prefix, 48 active subcarriers (IEEE 802.11a data-subcarrier layout), QPSK |
| Frame | 14 OFDM symbols = 1120 complex samples = 1344 bits; waveform normalised to unit average power |
| Noise | Complex Middleton Class-A, 30 mixture terms; total noise power set by Eb/N0 |
| Operating points | Eb/N0 ∈ {6, 10, 14} dB × A ∈ {0.005, 0.02} × T ∈ {0.05, 0.20} × seed ∈ {101, 202, 303, 404, 505} = **60** |
| Frames | 16 per operating point (960 in total); each operating point has its own seeded random stream |

### 5.2 Impulse-suppression pipelines

The in-phase and quadrature components are processed separately by the same real-valued transform. Periodization boundary handling is used throughout. For each component:

1. **Decompose** the component:
   - DWT: `wavedec`;
   - SWT: `swt`, undecimated;
   - WPT: full wavelet-packet tree, level-J leaves.
2. **Threshold each detail subband.** In each detail subband (each WPT leaf), a threshold T is computed from that subband's own noise estimate, σ = median(|c|)/0.6745. The coefficients with |c| ≥ T form the impulse estimate, shaped by the threshold rule:
   - hard: c;
   - soft: c·(|c| − T)/|c|;
   - garrote: c·(1 − T²/c²).

   All other coefficients, and the approximation subband, are set to zero.
3. **Reconstruct** the impulse estimate and subtract it from the received component.

### 5.3 Search space and selection

| Parameter | Candidates |
|---|---|
| Mother wavelet | db4, sym4, coif4 |
| Decomposition level J | 2, 3 |
| Threshold function | scaled MAD (T = 2.5 σ), universal (T = σ·√(2 ln n)), BayesShrink (T = σ²/σ_x) |
| Threshold rule | soft, hard, garrote |

That gives 54 configurations per family. The selected configuration of a family is the one with the **largest mean denoising gain** over the 60 operating points. Ties would be broken by the lower FLOP proxy; none occur.


### 5.4 Metrics

Each metric is computed per frame, averaged over the 16 frames of an operating point, and then summarised over the 60 operating points as mean ± 1.96·SD/√60.

- **ΔSNR (denoising gain):** SNR_out − SNR_in (dB). Each term is the complex SNR of the waveform before or after denoising, relative to the transmitted waveform.
- **NMSE:** Σ|q − q₁|² / Σ|q|², computed on the waveform. Because the transmitted waveform has unit average power, MSE = NMSE.
- **BER:** bit errors of the hard QPSK decisions divided by the number of bits.
- **EVM:** RMS error vector magnitude (%) of the 672 active-subcarrier symbols of a frame. A least-squares complex gain is removed first; it absorbs the fixed scaling between the unit-power waveform and the constellation.
- **Mean time:** wall-clock time to process one frame through the impulse-suppression block. It is the median of 3 calls, measured after 3 warm-up calls, and is reported in ms/frame.
- **Minimum frame budget T_frame:** the smallest frame duration for which the real-time indicator F_RT = 1.
- **FLOP proxy:** a deterministic multiply–accumulate count per frame of n = 1120 samples, with filter length L_f (8 for sym4):
  - DWT: 4 L_f Σ_{j=1..J} n/2^(j−1);
  - SWT and WPT: 8 L_f n J.

  
### 5.5 Statistical tests

The paired unit is the operating point (seed, Eb/N0, A, T), which is shared by the three selected configurations.

- **Friedman test:** across DWT, SWT and WPT for ΔSNR, NMSE, BER, EVM and mean time; n = 60 and 2 degrees of freedom.
- **Pairwise Wilcoxon signed-rank tests:** two-sided, with zero differences discarded. The Holm correction is applied over the 3 pairs of each metric. 

## 6. Setup instructions

Install Python 3.9 or newer from <https://www.python.org>. On Windows, tick **"Add Python to PATH"** during installation.

### Terminal only

Open a terminal in this folder and run:

```
python -m venv .venv
.venv\Scripts\activate             (Windows)
source .venv/bin/activate          (Linux / macOS)
pip install -r requirements.txt
pip install ipykernel              (only needed for the notebook)
```

On Windows, if `python` is not recognised, use `py` instead. On Linux and macOS, `python3` may be needed.

## 7. Run instructions

### 7.1 Terminal only

With the environment activated:

```
python transform_family_benchmark.py
```

For the notebook, run `pip install notebook`, then `jupyter notebook stage_by_stage_benchmark.ipynb`.


## 8. Reproducibility of the timing results

The processing times are wall-clock measurements of a software implementation on a general-purpose processor. They depend on the CPU, its power and clock settings, other running programs, and the Python and library versions. 

On other computers, the absolute times differ, but the ordering **DWT < WPT < SWT** is reproduced. 
For the most stable timings:

- close other programs;
- connect a laptop to mains power;
- run the script rather than the notebook.

The FLOP proxy is deterministic and does not depend on the computer.
